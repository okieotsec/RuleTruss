# UniFi example (fictional)

A synthetic zone-based gateway export written from the published UniFi API schema, and a small invented capture inside its networks. Press **Load the UniFi example** on the Import tab, or import both files and load `context.json` on Groups & labels. A real export is made with `tools/unifi_export.py` (see docs/EXPORT_UNIFI.md). Regenerate with `python tools/make_samples.py`.
